# Параметры и ROS-интерфейс

Параметры модели хранятся в [`config/parameters.json`](../config/parameters.json), а её геометрические данные — в [`config/geometry.json`](../config/geometry.json).

## Изменение параметров

Все параметры находятся в `config/parameters.json`. После изменений:

```bash
python3 tools/generate_model.py
```

Затем перезапустите симуляцию. Это обновит SDF и сцену; STEP и сетки
обрабатывать повторно не нужно. Генератор использует только стандартную
библиотеку Python.

Если CAD-отображение слишком тяжёлое для ноутбука, установите
`"visual_mode": "simplified"` и запустите генератор. Физика и размеры
контактных поверхностей останутся такими же, внешний вид станет проще.
Для камеры можно сначала уменьшить разрешение до 320×240 и частоту до 10 Гц.

## ROS-топики и координаты

| ROS-топик | Тип | Назначение |
|---|---|---|
| `/cmd_vel` | `geometry_msgs/msg/Twist` | команды пользователя |
| `/robot/cmd_vel` | `geometry_msgs/msg/Twist` | команды после повтора и таймаута |
| `/odom` | `nav_msgs/msg/Odometry` | кинематическая одометрия привода |
| `/ground_truth/odom` | `nav_msgs/msg/Odometry` | поза и скорость из физической симуляции |
| `/camera/image_raw` | `sensor_msgs/msg/Image` | изображение верхней камеры |
| `/camera/camera_info` | `sensor_msgs/msg/CameraInfo` | параметры виртуальной камеры |
| `/clock` | `rosgraph_msgs/msg/Clock` | симуляционное время |
| `/tf` | `tf2_msgs/msg/TFMessage` | odom → base_link |
| `/tf_static` | `tf2_msgs/msg/TFMessage` | base_link → camera_link → camera_optical_frame |

Положение `base_link` — на уровне пола между центрами гусениц, а не
в центре масс. `camera_link`: X вдоль взгляда камеры. `camera_optical_frame`:
Z вперёд, X вправо, Y вниз, как ожидают OpenCV и ROS изображения.
`ground_truth` имеет начало координат `world`; его TF не публикуется в общий
ROS `/tf`, чтобы не создавать вторую конкурирующую связь для `base_link`.

Для узлов локализации включите `use_sim_time:=true`. Кинематическая одометрия
не равна истинной позе при проскальзывании. В TrackedVehicle Harmonic она
рассчитывается из скорости лент как одометрия дифференциального привода;
при эффективности поворота меньше 1 её угол может расходиться с командным.
Сравнивайте алгоритм с `/ground_truth/odom`; `/odom` не служит эталоном.

Начальные параметры камеры: 640×480, 20 Гц, горизонтальный угол 60°.
Фокусное расстояние примерно 554.26 пикселя. Реальные K и дисторсия камеры
пока неизвестны; используйте приходящий CameraInfo для работы в симуляции.
Сцена содержит пол, две стены, препятствие и низкую ступеньку. ArUco-маркеры
пока не добавлены: их нужно размещать с известными размерами и позами.
